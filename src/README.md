# 微博助手 Weibo Saver

微博无损下载 + 去广告 + 大图浏览。油猴用户脚本。

## 安装

油猴菜单 → 管理面板 → 添加新脚本 → 打开下面这个链接（会直接弹出安装页）：

```
https://raw.githubusercontent.com/teddy4556/weibo-saver/main/src/weibo-saver-v0.1.33.user.js
```

或手动：下载 `src/weibo-saver-v0.1.33.user.js`，全选复制到油猴编辑器里保存。

## 更新

油猴面板里点「检查更新」，或重新访问上面的 raw 链接。

---

## 这是什么

装上之后，微博每条带图/视频的动态会在**时间戳后面多出一个小小的「下载」标签**，点一下就把原图/原视频存下来。

不需要复制链接，不需要开 DevSocket，不需要任何第三方服务。

## 功能

| 功能 | 说明 |
|---|---|
| 一键下载 | 每张卡片右下角常驻「下载」按钮；支持九宫格 / 视频 / livephoto / 长文 |
| 超高清图 | 走微博 ajax 下载接口，拿到的图比页面显示的清晰一档 |
| 超高清视频 | 走 tv 组件接口，按分辨率排序取最高画质 |
| 直播下载 | m3u8 自动解析分片，并发拉取后合并成 mp4 |
| 批量下载 | 面板第一行「📦 批量下载」→ 全选本页 → 下载所选 |
| 去广告 | 隐藏信息流推广位 |
| 大图浏览 | 九宫格滚动时自动换成高清图，不用点开放大 |
| 命名模板 | 默认 `微博#用户名#用户ID#序号.扩展名`，模板可自定义 |
| 打包下载 | 多文件打成 zip（默认关闭，需要时在油猴菜单开） |

## 用法

**单个下载** — 每条带图/视频的动态，**右下角常驻一个红色「下载」按钮**，直接点就行。

按钮平时是半透明的，鼠标移上去会变深。点击后变成「⏳ 下载中」，完成后变绿「✅ 完成」，失败变橙「↻ 重试」（可再点一次）。

下载中按钮会变成「⏳ 下载中」，完成后变绿「✅ 完成」，失败变橙「↻ 重试」。

**调快慢** — 面板第一行有个 `批3·260ms`，两个数字可以直接点着改。

- 数字越大越快，但丢文件风险上升
- 批大小设成 **1** 就是安全模式（全串行，永不丢）
- 油猴菜单里也有三档快捷：🐢 安全模式 / 🚀 极速模式 / ⚖️ 恢复默认

**批量下载** — 面板**第一行**的「📦 批量下载」按钮（最大的那个），点一下进入批量模式 → 顶部出现工具条 → 「全选本页」→ 「下载所选」。再点一次按钮退出。

批量模式下每条动态左上角会出现一个勾选圈，点「全选本页」可以一键全选，也可以手动挑。下载按顺序一条条来，不会并发打微博接口。

**关掉批量还能下吗？** 能。批量只是多一个勾选入口，关掉后回到最简模式 —— 鼠标移到动态的时间戳上，点右边的「下载」标签就行。

**改文件名** — 油猴菜单 →「🏷 设置命名模板」。当前默认：

```
微博#{username}#{uid}#{index}.{ext}
```

下载出来长这样：

```
微博#示例博主#1234567890#01.jpg
微博#示例博主#1234567890#02.jpg
微博#示例博主#1234567890#01-live.mp4
```

| 占位符 | 内容 |
|---|---|
| `{username}` | 原博主昵称 |
| `{uid}` | 原博主用户 ID（转发微博取原博的） |
| `{index}` | 两位补零序号，单图也是 `01` |
| `{ext}` | 扩展名 |
| `{mblogid}` | 单条微博短 ID |
| `{time}` | 发布时间 |

`#` 只是分隔符，去掉也能用。取不到的占位符显示成 `x`，不会留空。

不确定长什么样就点「👀 预览命名效果」，会用示例数据先给你看一眼。

**关掉增强** — 油猴菜单里「❌ 启用增强」一键关掉去广告 / 大图 / 批量，只留下载。改坏了也能一键还原。

| 指标 | 值 |
|---|---|

| 单图并发 | 3 路（超清模式）/ 5 路（普通模式） |

## 常见问题

**看不到卡片按钮 / 下载标签？**

打开油猴菜单 →「🩺 卡片识别诊断」，会弹一个框告诉你识别到几张卡片、走的是哪条识别路、页面里有多少图片和视频。

按钮显示不正常时，诊断弹窗会多三行计数：

| 计数 | 含义 |
|---|---|
| 未被开关隐藏 | 正常可见的按钮数 |
| 等待布局（懒加载） | 图片还没加载完，滚一下就会补上 |
| 尺寸太小（头像/表情） | 正确跳过，不是 bug |

| 诊断结果 | 意思 |
|---|---|
| 一张卡片都没识别到 | 微博在这个页面的结构又变了，把弹窗内容发给开发者 |
| 卡片识别成功但按钮没注入 | 「卡片按钮」开关被关了，面板上打开 |
| 一切正常 | 刷新一下页面试试 |

**Console 里的关键日志**

每次识别都会打一行：

```
[WeiboSaver-v0.1.6] collectCards: 卡片=12 | href路=30 属性路=0 媒体路=8 | 页面图片=24 视频=1 | /hot/weibo/102803
```

`卡片=0` 就是没认出来，其余数字能看出是哪条路在起作用。

**下载列表里看不到文件？**
旧版走页面下载通道，浏览器有「自动下载多个文件」的限制。现在改走扩展通道正常。
如果仍然没有，检查 Chrome 地址栏右侧有没有被拦截的下载图标，点开选择「始终允许」。

## 已知限制

- 微博 API 需要登录态，未登录时部分视频接口返回空
- 付费/粉丝专属微博的图片会自动降级到 mw2000（超清接口对这类微博不放行）
- 部分视频的高清地址需要额外接口换取，拿不到时自动降级到普通清晰度
- gif 图不走超清接口（会失败），自动降级
- 去广告基于文案和类名关键词，微博改版后可能需要更新规则
